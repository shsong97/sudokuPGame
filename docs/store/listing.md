## 간단한 설명 (80자 이내)

```
광고 없이 오프라인으로 즐기는 스도쿠. 난이도별 100개 퍼즐과 친절한 힌트.
```

## 자세한 설명 (4,000자 이내)

```
광고도, 회원가입도, 인터넷 연결도 필요 없는 스도쿠입니다.

■ 엄선한 100개의 퍼즐
쉬움·보통·어려움·전문가 4단계, 난이도별 25개씩 준비했습니다.
모든 퍼즐은 정답이 하나뿐이며, 사람이 쓰는 풀이 기법으로 끝까지 풀 수 있는지 검증했습니다.
같은 난이도 안에서도 쉬운 퍼즐부터 차례로 어려워집니다.

■ 배우면서 푸는 힌트
막히면 힌트를 눌러 보세요. 바로 정답을 알려주는 대신
어느 칸을 봐야 하는지와 어떤 풀이 기법(히든 싱글, 포인팅, X-Wing, XY-Wing 등)을 쓰면 되는지 먼저 설명합니다.
그래도 모르겠으면 정답을 확인할 수 있습니다.

■ 실수 3번이면 게임 오버
틀린 숫자는 바로 표시되고, 세 번 틀리면 게임이 끝납니다. 적당한 긴장감을 즐겨 보세요.

■ 편리한 기능
• 메모(후보 숫자) 입력과 자동 정리
• 실행 취소, 지우개
• 같은 숫자와 같은 줄 강조
• 자동 저장과 이어하기
• 퍼즐별 클리어 기록과 최고 기록
• 난이도별 통계 (승률, 최고·평균 기록, 힌트 사용)
• 라이트 / 다크 테마, 가로 모드 지원

■ 개인정보
이 앱은 인터넷 권한이 없으며 어떤 정보도 수집하거나 전송하지 않습니다.
```
